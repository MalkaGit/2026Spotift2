# Spotify-Like Web App – Plan (clientWorkspace-AI)

**Client app location:** `clientWorkspace-AI/` (repo root, sibling to `serverWorkspace`).

---

## 1. Goal

Build a **responsive React web app** (desktop + iPhone + iPad) that talks to the existing Node/Express REST API in `serverWorkspace/app-rest-api` and behaves like a simplified Spotify:

- New user after login → if library is empty → show Artist Search to pick 3 favorites.
- If library has items → show Favorites Library.
- User can sort library by **name** or **date added**.
- User can search artists and like them (library = likes).

---

## 2. Backend API (already implemented in serverWorkspace)

Base URL: e.g. `http://localhost:3000`.

- **Auth:** `POST /users/register`, `POST /users/login` (returns JWT).
- **Profile:** `GET /users/me` (requires `Authorization: Bearer <token>`).
- **Likes (library):**
  - `GET /users/me/likes?sort=created_at|name&direction=asc|desc&offset&limit` → `{ items: LikesItem[] }`.
  - `POST /users/me/likes` body: `{ entityType: 'artist'|'album'|'playlist', entityId: string }`.
- **Search:** `GET /search/v2/artists?q=&offset=&limit=` → `{ items: SearchItem[] }` (each has `id`, `name`, `imageUrl?`, `liked`).

---

## 3. User Flows

- **Login** → fetch `/users/me/likes` → if empty → `/onboarding/favorites`; else → `/library`.
- **Library:** list likes; sort by name or date; if empty → redirect to onboarding.
- **Onboarding:** search artists, like at least 3 → “Continue” → `/library`.
- **Search:** same search UI; like/unlike artists anytime.
- **Profile:** `GET /users/me`, show email/createdAt, logout.

## 5. State & Data Flow

- **AuthContext:** `user`, `token`, `login()`, `logout()`; axios interceptor adds `Authorization: Bearer <token>`.
- **useLibrary:** `items`, `sort`, `direction`, `loadLibrary(sort, direction)`, redirect to onboarding if empty.
- **useArtistSearch:** `query`, `results`, `searchArtists(q)`; like via `POST /users/me/likes` with `entityType: 'artist'`.

---

## 6. Navigation & Responsiveness

- **Routes:** `/login`, `/register` (public); `/library`, `/onboarding/favorites`, `/search`, `/profile` (protected).
- **Desktop:** left sidebar (Library, Search, Profile).
- **Mobile:** top bar + bottom nav; same routes.

---

## 7. Tech

- **Stack:** Vite + React + TypeScript, React Router, Axios.
- **Run:** `cd clientWorkspace-AI && npm install && npm run dev`; API at `serverWorkspace/app-rest-api` (e.g. port 3000).
