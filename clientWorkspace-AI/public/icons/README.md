# Icons (public/icons)

All action-bar icon assets for the app live here. Referenced in code as `/icons/filename`.

- **play.svg** – Play button triangle (artist overview). Green circle is CSS; the icon is this SVG.
- **follow.svg** – Follow icon (person + plus) from [IconApe follow-1.svg](https://iconape.com/wp-content/files/zf/10489/svg/follow-1.svg). Fill set to white for dark UI.
- **shuffle-off.png** – Shuffle off (add this file; e.g. [Veryicon shuffle-9](https://www.veryicon.com/icons/miscellaneous/standard-general-linear-icon/shuffle-9.html))
- **shuffle-on.png** – Shuffle on (add this file; e.g. [Flaticon shuffle 8345820](https://www.flaticon.com/free-icon/shuffle_8345820))
