# Plans

Design and implementation plans for use cases and features.

**Template.** Use [uc00011-backend-play-track-operation-v3.plan.md](uc00011-backend-play-track-operation-v3.plan.md) as the template for new UC/feature plans. It starts with a short "Template note" that lists the section order and purpose. A simpler variant (direct API updates, no worker) is [uc00011-backend-play-track-operation-v1.plan.md](uc00011-backend-play-track-operation-v1.plan.md).

**Entry points → plans.** [entry-points-to-plans.md](entry-points-to-plans.md) maps API endpoints and workers to their plan doc. When you add a new UC, add its entry point(s) there and link to the new plan.
